# Changelog

## 1.0.1

- Respect the main carousel's image fitting setting and keep the whole image visible on hover when selected.
- Expand the installation guide with content selection, publication and page embedding steps.
- Clarify support wording and troubleshooting for missing templates and empty carousels.
- Warn when the main carousel plugin is missing, inactive or older than 2.0.0.
- Align the WordPress requirement in the plugin header with the readme.

## 1.0.0

- Initial release of the Aurora Cards universal template.
- Added blog, page, custom item and WooCommerce product presentation.
- Added optional WooCommerce prices, ratings, sale details and add-to-cart actions supplied by CCI Posts Carousel Pro. Aurora Cards works with the base carousel plugin without Pro.
- Added linked category and tag archives with complete hover and keyboard focus states.
- Refined carousel spacing and card shadows so slide shadows remain distinct.
- Added Owl navigation and pagination styling for both `div` and `button` control markup.
- Added responsive Aurora styling for the optional Pro autoplay progress indicator.
- Standardized the package metadata and release archive on GPL-2.0-or-later.
- Standardized carousel navigation as stable 44px brand-colored controls with visible hover and keyboard-focus states.
- Removed card elevation and lift inside narrow Aurora containers so shadows cannot be clipped in sidebars or article insets.
