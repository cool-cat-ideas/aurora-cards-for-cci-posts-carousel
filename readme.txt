Use one recognisable card style for posts, pages and product links in the same carousel.

== Description ==

Aurora Cards gives posts, pages and product links the same card style. Categories and tags link to their archive pages. The cards include visible hover and keyboard focus states.

Aurora Cards requires CCI Posts Carousel All In One 2.0.0 or newer. It works with the base plugin and does not require Pro or a license key.

Posts, pages, manual slides and ordinary product links use the same template. Current WooCommerce prices, ratings, sale information and add-to-cart actions are optional details supplied by the main CCI Posts Carousel All In One Pro package. Aurora Cards has no separate paid edition.

Content selection, order, navigation and responsive settings stay in the main carousel editor. This plugin adds the template and its styles without introducing a second editor.

== Installation ==

1. Install and activate CCI Posts Carousel All In One.
2. Install and activate this plugin.
3. Edit a saved carousel and choose **Aurora Cards** under **Template**.
4. Save and check the carousel on desktop and mobile.

If Aurora Cards is missing from the template list, confirm that Aurora Cards 1.0.0 or newer and CCI Posts Carousel All In One 2.0.0 or newer are active.

== Frequently Asked Questions ==

= Does Aurora Cards require Pro? =

No. Posts, pages, manual slides and product links work with the base CCI Posts Carousel All In One plugin. Pro is needed only for the optional WooCommerce prices, ratings, sale details and cart actions.

= Can I use Aurora Cards without CCI Posts Carousel All In One? =

No. It adds a template to CCI Posts Carousel All In One and does not render a carousel on its own.

= Why do product cards show links instead of prices? =

That is the base plugin's product presentation. Live store details come from the WooCommerce module included in CCI Posts Carousel All In One Pro.
